# V0.3 发布说明

## 已实现

- Python Collector 支持 `mysql`、`kafka`、`dual` 三种输出，默认仍为 `mysql`。
- `StockDailyEvent` 在 Python/Java 之间使用严格 camelCase JSON 契约。
- 新增可复用的 `StockBasicEvent` Java 契约与标准 JSON fixture。
- Java Consumer 校验字段、Kafka Key 和可配置 `schemaVersion`。
- JSON、字段、协议版本异常发送 DLT；DLT 失败时不确认原消息。
- 新增线程安全的进程内统计和容量可配置的最近错误队列。
- 新增 `/api/consumer/statistics`、`/api/consumer/errors` 和 `/monitor/`。
- 新增跨语言 smoke 与 dual-output 对账脚本。
- `stock_daily` 行情数值字段从 `FLOAT` 迁移为定点 `DECIMAL`，避免新写入数据出现二进制浮点存储误差。
- 新增可复现的影子表复制、原子切换和旧表清理 SQL。

## 运维边界

- 监控状态随 Java 进程重启清零。
- 最近错误不包含完整原始 payload。
- Java V0.3 不写 MySQL/ClickHouse，不计算指标或交易信号。
- Kafka 故障回滚：设置 `COLLECTOR_OUTPUT_MODE=mysql` 后重启 Collector。
