# 数据准备后的后台特征暂存

管理员在`股票池管理 → 固定池数据准备任务`中选择已补齐的任务，点击“构建特征暂存（不启用）”。确认后只创建队列任务，不在HTTP请求中计算，也不会自动启动worker。

可以点击“查看特征任务”进入现有任务页，查看进度、事件、绑定及取消。关闭网页不影响已运行任务。普通用户不能创建、查看或取消后台任务。

## 输入与产物

- 只有已提交且所有关联日任务成功的READY_CORE准备任务能申请。无适用交易日、排队、失败或异常关联都不能直接构建。
- 绑定准备任务、批次、固定池版本及成员摘要；这些证据变化后执行失败，不静默换池。
- 特征库是全局共享的：从2023-01-01开始计算已入库的沪深A股历史，不只保留所选池。截止取准备范围结束与当前启用特征库截止的较晚者，不能越过可信日历中的已完成交易日。
- 准备池只数与全局构建只数不同，任务详情分别说明。全局源存在缺少每日基本指标或股票主档的记录时，原有快照校验会失败，不跳过或补造。
- 沿用现有按股票读取、分批写入的特征计算算法。源快照、报告及摘要保存在配置的TRAINING_ARTIFACT_ROOT下的新任务目录，暂存表和build_id使用任务编号。
- 成功表示源快照文件、报告及数据库暂存元数据已核对，不是已启用、模型就绪、训练或策略效果验收。模型仍须独立样本与来源校验。

## 执行与安全

复用原训练worker单执行槽、心跳、进程树控制、取消与隔离机制，不增加第二套计算队列。现有工程资源限制继续生效：执行前至少8GiB可用内存和16GiB可用磁盘；进程树上限6GiB，运行时至少2GiB剩余磁盘，最多60分钟。超限失败不会缩小股票池重试。

已有基础数据库/任务/特征元数据迁移仍需完成；新任务类型不新增队列表，也不会自动迁移。运维需明确启动原`python scripts/training_worker.py run`才会领取任务。不要在未核实旧进程退出时清除隔离标记，也不要同时用CLI修改特征发布或启动额外构建。

当前特征启用仍是独立的受控运维步骤，新网页任务不会执行它。自动启用、父任务接模型及每日预测尚不属于这个暂存入口；不应把“暂存成功”当作这些功能已经完成。

中断、取消和失败保留独立暂存证据，不覆盖旧模型、旧快照或当前特征库；不自动清表、重试或恢复进程。必要时由管理员修复原因后显式创建新任务，不复用旧任务目录。

## REST

`POST /api/admin/preparation/requests/{id}/feature-build`，请求体为空JSON对象`{}`，必须是受保护管理员会话，并携带合法Origin、CSRF及32位十六进制Idempotency-Key。

201只表示任务入队；同一账号和key重复提交返回原任务。409表示准备任务尚未就绪或提交冲突，404表示不存在，503表示依赖未就绪。接口不接受文件路径、任意SQL、训练参数、发布日期或启用开关。

读取进度、事件及取消沿用`/api/admin/training/jobs`接口。任务类型是`feature_build`，不会注册到模型或已发布结果库。首次没有启用特征库时，工程训练能力页可能显示未就绪，但独立任务列表和特征任务详情仍可读取。
