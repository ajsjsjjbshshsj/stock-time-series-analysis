# LightGBM 独立训练／验证实验

这个入口只做本地运维人员显式启动的研究实验，不是客户端训练接口，不修改原 `bounded_v1`、模型注册表或已发布结果。输入来自一个成功全市场工程任务的已封存候选和原磁盘矩阵；复用其**仅在外层训练期产生的探针特征**，不在验证期重新选特征。

## 运行

在 `python-services/stock-analysis-app` 下运行，替换成自己的成功任务 ID：

```powershell
python scripts/validate_market_candidate.py --task-id cf4f07c0bf0948dba20e281214880e3b
```

只接受 `--task-id`、`--project-root` 和 `--output-root`，不接受任意模型参数或测试集运行开关。默认读取项目 `.env`；沿用 `TRAINING_ARTIFACT_ROOT`、`TRAINING_CALENDAR_FILE`、`PREPARATION_DATA_ROOT` 与运行路径映射。原矩阵位于候选根目录同级 `work/<task-id>`，必须保留。项目在不同机器上恢复后应配置路径映射，不修改封存内容。

每次新建 `.runtime/training_tasks/validation_experiments/<UUID>`。输出不得与旧候选、原矩阵、来源证据、模型目录或 Git 元数据重叠；不覆盖、续写或冒充旧工程候选。发现输入变化、活跃训练队列、来源绑定不一致或损坏缓存时拒绝运行。不联网补采，也不绕过网页角色权限新增任何公开训练接口。

## 固定四组协议

| 实验 | 拟合标签 | 早停指标 | 最多轮数／耐心 |
|---|---|---|---|
| `raw_rmse20` | 原五交易日未复权收益 | RMSE | 20／10 |
| `raw_rmse300` | 同上 | RMSE | 300／30 |
| `raw_rankic300` | 同上 | 逐日等权 RankIC | 300／30 |
| `csrank_rankic300` | 原标签的当日平均排名，中心化 | 逐日等权 RankIC | 300／30 |

其他设置一致：随机种子 42、CPU 线程 2、63 叶、学习率 0.05、63 个分箱。排名标签只在每个已提供分区的同一日期内计算；该模型输出排序分数，不是收益或股价预测，不能与原收益标签直接计算有相同量纲的 RMSE。

## 时间隔离

外层训练、验证、测试区间以及固定股票池和 ID 都不改动。外层验证按完整信号日期先后拆成 60% 早停段、40% 候选比较段；早停段只有标签目标日早于比较段首日的行可用，边界不按简单行数切割。外层训练标签目标不能跨入验证期，整个外层验证标签不能跨入测试期。

四组预先登记后逐组拟合：只用训练段学习，只用早停段选择轮数，随后才预测比较段。比较段不作为 LightGBM 的验证数据集或特征筛选输入。新模型不对测试行拟合、预测或计算指标。为核对完整性，会读取原候选既有重加载证明、哈希原矩阵文件并校验测试索引元数据；这些操作不是重新评估测试集，不允许据此选择配置。

RankIC 先在每个日期内计算 Spearman 相关，再按日期等权平均。全相同分数或全相同标签的日期为“不可定义”，不伪装成零，也不以股票数量加权。报告保留逐日数据和可定义日期数。

## 结果含义与完整性

比较段平均 RankIC 最大者记录为 `best_trial`，同分按名称排序。`qualified=true` 还要求它不是对照组、对照 IC 可定义、平均 IC 为正且严格超过对照、所有比较日均能定义 IC。对照 IC 不可定义时仍保留最佳实验，但不宣称胜出。这个保守筛查可能拒绝偶有全同分数的模型，**不是统计显著、盈利或可上线的证明**。比较过四个候选的区间也不再是未触碰的最终留出集。

每组保存原生模型、比较段预测、逐日指标、参数、轮数，以及仅来自比较段的重加载证明。根目录保存预登记协议、净化后的行索引、原候选／矩阵／来源／代码哈希、报告和完成封存。验收要求完整文件清单、来源绑定与探针特征一致、分区索引及时间隔离一致、四组比较样本一致，并从比较段文件重新计算指标和量纲检查，不只检查文件哈希。只有四组全部完成并通过验证的 `VALIDATION_ONLY_COMPLETE` 才可视为完成；失败或中断目录不能当作完成结果。所有结果固定 `test_evaluated=false`、`published=false`，不自动替换任何模型。

预检要求至少 8 GiB 可用内存、16 GiB 磁盘；运行预算为总计 1 小时、6 GiB 进程树内存及至少 2 GiB 剩余磁盘。入口在训练回调和分批预测时检查预算；正式长任务还应由独立进程监管，才能覆盖原生数据集构建等回调之外的阶段。这不是自动启用 CUDA 或申请云计算资源。
