# 真实分析入口

登录后的`/#/analysis`保留原地址和标签，但在真实/受保护模式下不进入旧演示训练或模拟结果面板。管理员通过页面上的股票池、模型工作台和后台任务链接执行管理操作；分析标签本身只读。

| 标签 | 真实来源与边界 |
| --- | --- |
| 综合概览、基本行情 | market-api日线、估值；缺记录与依赖故障分别呈现 |
| 技术指标、统计分析 | 复用客户端组件，读取真实日线后在浏览器计算并明确标注；仅针对接口返回的有限窗口，不是全历史特征库或ClickHouse指标结果 |
| 模型预测 | 原真实模型注册/预测及滚动评估只读视图 |
| 策略回测 | 管理员已审核发布的backtest报告，默认权益分区，可查看成交、未成交及退市处理 |
| 选股排名 | 已发布predict报告的分数分区；固定池范围、日期和模型以各报告为准，不冒充全市场排行 |
| Transformer | 仅Transformer已发布报告；历史冻结试点信号在单独折叠区，展开才读取，明确不是当前预测 |
| 风险提示 | 风险声明及原真实发布摘要 |

发布列表每次最多读取20条，过滤仅作用于当前页。当前页没有匹配结果不意味着所有历史都没有，可点击“更早发布”继续查询。结果读取仍校验后端封存证据，故障显示错误，不回退mock。客户端`/#/user`沿用只读权限，不新增管理链接或训练请求。

演示模式保留原面板和明显标记，与已发布真实结果分离。查看页面不补采、不训练、不推理，也不会自动发布任何结果。这里的技术和统计计算仅生成浏览器图表，不是后台模型任务。
