# V0.3 Completion Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete and verify the V0.3 Python → Kafka → Java vertical slice, including monitoring APIs, a lightweight browser dashboard, cross-language reconciliation, failure isolation evidence, and release documentation.

**Architecture:** Keep Python responsible for collection, event creation, MySQL/Kafka output, and producer delivery counts. Kafka remains the language boundary. Java consumes raw JSON, validates the shared contract, isolates bad records, records in-memory monitoring data, and serves read-only monitoring APIs plus a static `/monitor` page.

**Tech Stack:** Python 3.12, pytest, confluent-kafka, Java 21, Maven, Spring Boot 4.1, Spring Kafka, Jackson, Micrometer, HTML/CSS/JavaScript, Docker Compose, Apache Kafka, Kafka UI.

## Global Constraints

- Work on branch `codex/consumer-monitoring-reconciliation` and push only to personal Fork `origin`.
- Merge Requests must be opened from the personal Fork to `ybw-group/kafka-stock-project`.
- Do not commit `.idea/`, `Java/`, credentials, Tushare tokens, generated test output, Maven `target/`, or Python caches.
- Preserve V0.2 collection, MySQL, history-backfill, and retry behavior.
- V0.3 must not introduce Flink, ClickHouse, Redis, Spark, Iceberg, MinIO, Airflow, or real-time indicator calculation.
- Java Consumer must not write MySQL or ClickHouse.
- `stock.ods.daily.v1` uses Kafka Key `tsCode`; rejected records go to `stock.dead-letter.v1`.
- A source record is acknowledged only after successful handling or successful dead-letter publication.
- Monitoring state is process-local and resets when the Java service restarts; persistence belongs to a later version.
- Every new behavior follows RED → GREEN → full regression verification.
- PowerShell commands documented for users must remain on one line.
