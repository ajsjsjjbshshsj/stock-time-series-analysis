# 股票池网页管理

管理员在 `/#/pools` 选择全市场、沪深300、中证1000或行业，先预览本地成员，再明确点击“保存固定版本”。此操作仅保存成员元数据；不采集、不训练、不修改已发布模型，也不更改原默认版本。普通用户不能操作此管理接口。

## 来源和版本

- 全市场只取已入库 `stock_basic` 中的沪深A股，排除北交所及其他证券类型；行业使用该表当前分类。它不是历史行业成分，也不能冒充东方财富行业分类。
- 指数读取 `stock_constituent` 中不晚于所选截止日期的最新快照；沪深300必须恰好300个合法成员，中证1000必须1000个。缺失、不完整或混入范围外成员时不可用，不替换成全市场，也不自动请求Tushare。来源日期可明显早于今天，页面必须显示真实日期。
- 旧 `tushare.index_weight` / `akshare.eastmoney` 来源版本继续保留；新本地数据库版本明确标为 `local.stock_basic` 或 `local.stock_constituent`（schema2）。二者不混淆，不改写旧快照。
- 沿用原三张 `stock_pool_version` / `stock_pool_member` / `stock_pool_active`，不新增股票池表。显式保存通过原 `PoolRepository`，不更新active指针。已有项目迁移应先执行；HTTP不自动建表。
- 保存以预览的内容版本为条件，成员来源改变则409，要求重新预览。保存后读取该固定版本，不跟随行业分类、指数成分或名称变化暗中换股。成员顺序和hash经原仓库校验。
- 固定快照在整个历史分析区间内保持同一簇股票，**不是各历史日的动态指数成分**，有幸存者偏差。它不能作为无偏历史指数回测的保证。

## 覆盖查询

选择已保存版本和日期范围，然后手动“查询固定版本覆盖”。每页最多50只，页面20只；统计仅属于当前页，不代表整个股票池总量。不在API中加载全市场历史价格，不校验价格数值。

日期从2023-01-01起；上海时间严格大于16:00才允许查询当天，否则上限前一天。使用可信本地交易日历，不用周一至周五猜交易日；无可信日历、上市资料或来源证明时显示未就绪，不把故障转换成零缺口。

上市前、退市后及代码独立有效期外不计适用交易日，仍保留该成员在结果中的位置。沿用已存在的代码边界，不复制或关联新旧代码行情。已验证全天停牌单独统计；不能解释的无报价日期是“待核对”，不自动等同缺数据或停牌。有报价却缺每日基本指标另计。来源资料早于区间截止时明确警示，之后上市/退市变动仍需核对。所有显示都是行存在性统计，**不代表因子、执行证据或模型输入已完整**。

页面只读查询不触发补采，既有模型仍采用原固定参数和池限制。XGBoost单股、LightGBM全市场和Transformer10–20只的后台适配不因股票池页面改变。后续如需模型采用所选版本，应另行实现并验证模型契约。

## API与运行

所有接口为 `/api/admin/pools/*`，复用已有受保护FastAPI、管理员鉴权和 `/api/admin/` 代理；写操作校验Origin和CSRF。

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/catalog` | 可选行业、指数本地日期、日期上限 |
| GET | `/candidate?kind=market&code=SH_SZ_A` | 不写库的预览，最多返回20个成员 |
| POST | `/snapshots` | `{kind,code,as_of,expected_version}`，保存内容匹配的固定版本 |
| GET | `/versions?limit=20&offset=0` | 已保存版本，不改active |
| GET | `/members?version=...&limit=20&offset=0` | 经验证的固定成员分页 |
| GET | `/coverage?version=...&start=2023-01-01&end=2026-10-13&limit=20&offset=0` | 当前页覆盖统计 |

指数可指定`as_of=YYYY-MM-DD`；全市场和本地行业只支持今天的分类日期，不能回填成历史成分日期。版本格式仅接受已有`pool_...`或兼容`csi300_...`；不接受文件路径、任意SQL或客户端成员列表。

API与collector配置同一MySQL及`PREPARATION_DATA_ROOT`/`RUNTIME_PATH_MAP_FILE`。覆盖复用本地封存日历、上市资料和停牌来源验证；`TRAINING_CALENDAR_FILE`可提供原可信日历，范围不足时只查本地sealed缓存，不联网刷新。凭据、映射、运行缓存和测试不提交GitHub。
